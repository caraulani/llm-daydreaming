Returns policy friction points

## Current policy language

30-day return window on most items. Restocking fee 15% for non-defective goods. Original packaging required. Customer pays return shipping for non-defective items. Policy is on checkout page and in order confirmation email.

## Most common complaints

Size issues: 40% of returns. Customers say size charts are unclear, images don't show true fit. Asked for model height/weight in product detail but haven't updated yet. No structured data on this.

Shipping cost shock: second most common. Customers expect return shipping included or claim they weren't told. The email link to the policy gets clicked 8-12% of the time based on email tracking. Return label generation is clunky, requires three clicks from the help desk.

## Numbers

~120 orders monthly, ~8 returns per month average. Returns rate spiked to 12% in August. No data on whether 15% restocking fee deters repeats. Disputed fee refunds account for 20% of support tickets related to returns.

## Next steps noted

Rewrite returns section in simpler language. Test version without mandatory original packaging language. Add return label link directly in order status page, not buried in email.
