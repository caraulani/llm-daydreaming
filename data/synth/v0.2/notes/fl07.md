# Full Eval Run Costs and Token Distribution

## Typical Pipeline Spend

Ran a baseline eval yesterday. Full stack (generation, criticism, matching) on 240 note pairs:
- Generation stage: ~185K tokens in, ~42K out. Haiku class model. Cost per run ~$0.80 at current rates.
- Criticism (3 critics, primary + 2 alternates): ~180K tokens per critic, ~15K output each. Secondary critics add ~35% overhead but useful for T8 comparison.
- Embedding + retrieval (dupgate): ~80K tokens for corpus novelty pass. Lighter than the LLM stages.

## Token Allocation

Most expensive phases in order: generation prompts (long context window), criticism passes (multiple judges), embedding retrieval. Generation dominates if pairs are large or domain-complex. Primary critic feeds dupgate and main tables; alternates exist for comparison only.

## Cost Control Levers

Haiku vs Sonnet trade-off: Haiku saves ~60% per token but needs longer prompts for some domains. Tested and held quality. Batch runs overnight when possible, fewer real-time constraints.

## Next Run Planning

v0.2 scaling to 500 pairs, two writer families. Projected: ~$2.20 full pipeline. Token budget tighter if adding novelty depth or longer gold standards. Watch context length on the generator stage, that's where per-run cost spreads.
