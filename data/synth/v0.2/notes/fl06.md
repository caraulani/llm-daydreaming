## Sampling Strategy

- Include 20% of rare but critical use cases
- Use historical data from client evaluations 
- Randomly select 50% of known edge cases
- Ensure at least 3 samples per unique LLM feature tested

## Example Scenarios

- Complex legal contract analysis
- Extremely niche medical diagnosis queries
- Ambiguous customer service requests
- Highly technical software development questions

## Testing Protocol

- Review past client feedback for patterns
- Consult with domain experts to identify edge cases
- Use automated tools to surface rare inputs
- Manually curate a balanced sample set
