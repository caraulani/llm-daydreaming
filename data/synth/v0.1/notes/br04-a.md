# Landing Page Variant Testing

## Week 1: Daily Tweaks

Adjusted the landing variant daily to match inbound traffic patterns. Morning cohort responded to blue CTA and minimal hero. Afternoon shoppers favored the product carousel. Swapped heading copy, button colors, and image placement based on hourly traffic breakdown. Logged each change in the run sheet.

## Reported Lift

Variant delivered 22% conversion lift that same week. Metrics looked solid at the time. Sent results out to stakeholders. Numbers felt clean enough to flag as a win.

## October Reversal

Ran the same variant unchanged throughout October. The lift disappeared by mid-month. Both variant and control converged back to baseline conversion rates. Spot checked the data multiple times.

## Current Operations

Stopped daily tweaks. Running weekly snapshots now. Inventory turnover has been cleaner this quarter, which helps the conversion picture. Standard A/B testing cadence going forward.
