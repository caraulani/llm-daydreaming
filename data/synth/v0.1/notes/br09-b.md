# Weekly dose tracking

## Protocol structure
- Protocol states weekly maximum dose; nothing on daily distribution
- Using spreadsheet: date, dose, running weekly total
- Resets Monday, 4 weeks in (Sept 1-13 current window)
- No daily guidance or app-based restrictions

## Pattern observations
- Sept 2-3: skipped Tuesday, took 2x Wednesday morning
- Sept 10-11: skipped Friday, took 2x Saturday morning
- Both weeks ended at 7 total, within protocol spec
- Tracker records only the weekly sum, doesn't flag the skip-then-double pattern
- Protocol doesn't restrict this approach

## Tracker limitations
- No daily pattern view, only cumulative weekly number
- Protocol is silent on dose clustering vs. spreading across the week
- No distinction visible between consistent daily and irregular daily
- Can't track whether pattern consistency affects actual outcomes
- Weekly reset means no month-to-month historical view
