# Full eval run costs and token flow

## Total spend for micro run (claude-3-5-haiku)

- 3 stages: generator, critic, dupgate
- 127 pair samples, each stage hits the model once
- Total: ~45k tokens in, ~12k tokens out (estimates, actual logged in metadata.yaml)
- Cost roughly $0.07-0.09 per run at haiku rates
- Runs in ~8-12 minutes, API limited

## Token distribution

Generator (most expensive stage):
- One prompt per pair arm (127 pairs = 254 calls)
- Each call: ~300 tokens in (context + prompt), ~150 tokens out (generated text)
- Roughly 75k total tokens through generator alone

Critic (binary scoring):
- Same 254 calls, lighter payload
- ~150 tokens in (prompt + generated text), ~50 out (keep/kill + reason)
- Roughly 25k tokens through critic

Dupgate (novelty gate):
- 254 calls to embedding model (not token-counted by Claude)
- ~100 tokens in (embed query), minimal text out
- Filtering happens on cosine distance, not tokens

## Cost tracking

Logged in metadata.yaml per run:
- input_tokens, output_tokens per stage
- model_id (exact, never alias)
- Multiply by provider rates: haiku $0.80/$2.40 per M
- Sonnet 3.5 would cost 5-7x more; opus 10-15x

Running 30 eval cycles for a client engagement: ~$2-3 total. Budget that in the project scope.
