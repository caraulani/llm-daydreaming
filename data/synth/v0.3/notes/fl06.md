Caching Judge Calls

## Goal
Reduce cost of evaluating large language models (LLMs) by caching judge call outputs based on item hash.

## Method
- Use item hash as key for cache lookup.
- Store results in Redis database.
- Implement check before each run to see if output already exists.

## Benefits Observed
- Cost savings up to 30% after initial setup.
- Time saved: 15 minutes per evaluation cycle.
- Less strain on LLM systems, smoother operation.

## Challenges Faced
- Initial implementation took 2 days.
- Debugging cache inconsistencies cost extra time.
