# Enclosure reprint at lower bed temp

## First print (failed)
- PLA enclosure for weatherstation sensor cluster, 12h print job
- Warped significantly mid-print, edges curled upward
- Bed temperature was 60°C (material batch spec sheet recommends 50-55°C)
- Corners lifted from buildplate around hour 6 of print
- Failed end-state: gaps in corners, part unusable for electronics fit

## Reprint (in progress)
- Reduced bed temp to 50°C, nozzle held at 200°C
- Using identical design file, no geometry changes
- Added 8mm brim around perimeter for extra buildplate adhesion
- Print speed reduced from 60 to 45 mm/s to allow better cooling
- Live monitoring shows clean first layer adhesion
- Expected completion: 10 Sept morning

## Post-print checks
- 24h cure time before removing supports
- Test dimensional fit on PCB mount points (4 standoffs, M2 holes)
- Verify sensor port hole: 8mm nominal, tolerance ±0.5mm
- Sand as needed at enclosure seam for weathersealing
