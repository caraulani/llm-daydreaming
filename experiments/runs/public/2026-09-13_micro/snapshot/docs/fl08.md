# Manual Review Queue Hold Duration

## Current SLA
- 72 hours is the hard ceiling for most holds. Longer and customers escalate to support team.
- First 24 hours: automatic cascade, pattern scoring, velocity checks.
- 24-48 hours: manual review slot typically opens if auto-clear didn't fire.
- Beyond 48 hours: needs explicit override reason logged.

## Queue backlog dynamics
- Peak fraud spike (March 2026): queue backed up to 150+ transactions. Manual review lag hit 96 hours.
- Reduced threshold temporarily. Cleared backlog in 7 days but false positive rate jumped 8%.
- Now running 40-50 items daily. Realistic manual window: 36-48 hours for lower-risk flags.

## Hold mechanics
- Transaction marked "under review", customer sees pending status, payment gateway holds funds.
- If cleared after 72h, auto-release. If rejected, customer gets fraud notice and can dispute.
- Disputed holds that go past 5 business days trigger payment processor escalation. They start their own investigation.

## Next steps
- Testing longer hold windows (up to 96h) for high-confidence fraud patterns.
- Need alert if queue sits over 48h average. Auto-escalate to secondary reviewer at that point.
