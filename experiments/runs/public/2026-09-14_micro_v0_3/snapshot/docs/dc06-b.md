Export Format Overview

EvalBench Pro exports in CSV format. Each run has a unique identifier stored in 'run_id' column.

## Run Identifier Field Details
- Located in first row under header 'run_id'
- Format is alphanumeric string, 12 characters long
- Example: 'R7N3P9T8U4G5'

## Export Process Steps
- Navigate to dashboard overview page
- Click 'Export Data' button on top right corner
- Choose 'CSV' as file type option
- Confirm export by clicking 'Download Now'
- File saves in downloads folder named 'eval_data.csv'

## Troubleshooting Common Issues
- Ensure all necessary data selected before exporting
- Check for any trailing commas or empty cells post-export
- Validate run_id matches expected format
