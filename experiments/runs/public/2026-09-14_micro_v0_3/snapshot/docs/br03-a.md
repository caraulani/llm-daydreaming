## Returns spike on 1200 series

"Not as described" complaints running at 9% for SKUs 1200–1399 versus 3% on legacy stock. Clear pattern since last week.

## Inventory refresh, July onwards

Added 1200+ SKUs after 3 July. New batch has descriptions from a different workflow than the older products, which kept hand-written copy. Pre-July stuff holding steady in customer satisfaction.

## What customers are flagging

Missing specs, color mismatches, sizing details off. All clustering in 1200+ returns. Older SKUs not seeing the same volume of these complaints.

## Action items

Pull 5-10 description samples from each cohort and compare. Check if photos or warehouse picks are also drifting. Audit the new batch before scaling campaigns on that inventory.
