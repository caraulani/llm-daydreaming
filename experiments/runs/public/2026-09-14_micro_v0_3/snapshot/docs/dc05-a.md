# Helpdesk portal response times: Tuesday advantage

## The pattern

- Portal helpdesk answers fastest on Tuesdays, avg 2-3 hours vs 6-8 hours other weekdays
- Tuesday is their full-staff day: all support personnel work, no rotation gaps
- Monday through Wednesday queries get responses; Thursday/Friday slowdown begins
- Verified across 15 grant applications, Jan to Sept 2024

## Application workflow impact

- Submit Thursday/Friday if possible to reach queue on Monday (avoid 48h wait)
- Tuesday submission gets handled same day if under 20 queries ahead
- Aim for 9am CET Tuesday for highest throughput
- Queries on status checks answer fastest; technical clarifications lag by 1-2 days

## Documentation turnaround

- Full staff can review attachments in parallel on Tuesdays
- Feedback on project narrative or budget section typically comes back Tuesday evening
- Single-staff days (Wed/Thu) only handle the highest priority queue
