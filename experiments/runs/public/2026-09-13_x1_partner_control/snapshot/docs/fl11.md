# Refund Policy for Abuse Closures

## Detection & Closure Process

- Fraud pattern identified: chargebacks, payment misuse, platform abuse
- Account suspended pending review, 72hr notification window
- If abuse confirmed, account permanently closed, user notified with reason code
- Cannot reactivate same payment method or linked email

## Refund Eligibility

- Pending charges: refund to original payment method within 5 business days
- Completed charges: case-by-case, depends on charge date and reason code
- Subscription credits: non-refundable, forfeited on closure
- Third-party payouts: flagged for recovery if reversed later

## User Communication

- Boilerplate email includes appeal process, 14 days to submit one appeal
- If appeal approved, restore account with payment restrictions (prepaid only)
- If appeal denied, no further communication standard
- Log all interactions in case file for compliance

## Special Cases

- Multiple accounts from same device: treat as coordinated abuse, block all
- Legal holds: preserve records for 90 days minimum
- Chargeback disputes: keep refund on hold pending resolution with issuer
