Pairwise and absolute scoring debate

## Method Comparison
- Pairwise: compares models against each other directly in pairs.
- Absolute: rates each model on an independent scale.

## Client Feedback
- Clients prefer pairwise for fairness, transparency.
- Some find absolute easier to understand initially.
