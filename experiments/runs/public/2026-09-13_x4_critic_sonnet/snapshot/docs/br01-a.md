## Support Queue Timing

Refund requests consistently spike in the two days following each promo code launch. Happened with the back-to-school push in late August, the labor day code in early September, and the flash sale codes last week. Support categorizes these as buyer's remorse patterns. The correlation is tight enough that I could set a calendar alert now.

## Approval Workflow

Current process has support approving refunds from the queue without checking payment method age. Keeps the queue moving quickly, no friction in sign-off. Most refunds hit approval within 24 hours of the request. The looser criteria make sense for throughput, but worth noting as a baseline.
