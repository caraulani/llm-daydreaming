## Account Takeovers

Last month, saw 14 cases where accounts were taken over. All of these had PINs left at 0000. Setting up the system allows users to skip choosing a PIN.

## User Behavior Insights

Accounts with chosen PINs remained secure from takeovers during this period. Considering the ease with which these accounts can be compromised, it seems critical for users to set unique PINs.

## Security Recommendations

Recommendation: Encourage users to select a custom PIN to enhance account security. Further research into user behavior and incentives may help drive adoption of stronger security practices.
