# Cite

The repository ships a `CITATION.cff`; GitHub's "Cite this repository" button reads it. The code is archived on Zenodo.

- Concept DOI, always the latest release: [10.5281/zenodo.22746627](https://doi.org/10.5281/zenodo.22746627)
- Release v0.2.0: [10.5281/zenodo.22746628](https://doi.org/10.5281/zenodo.22746628)

```bibtex
@software{caraulani2026daydreamd,
  author  = {Caraulani, Julian},
  title   = {daydreamd: the LLM daydreaming loop, evaluated},
  year    = {2026},
  version = {0.2.0},
  doi     = {10.5281/zenodo.22746627},
  url     = {https://github.com/caraulani/llm-daydreaming}
}
```

Paper title, for reference lists: "daydreamd: A Selection Engine for Machine-Generated Connections over a Private Corpus, Evaluated by Planted-Bridge Recovery" (Julian Caraulani, 2026). An arXiv identifier will be added here once the preprint is posted.
